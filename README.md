## 使用说明

- 日常同步由 GitHub Actions 在线完成，本地电脑无需保持运行。
- 在 [config.yml](config.yml) 的 `github.excluded_repositories` 中维护不参与记录和统计的仓库。
- 在 [notes.yml](notes.yml) 中为 PR 添加分类、个人总结或重点标记。
- 首次上线所需的 Token、Secret 和 Actions 权限配置见 [docs/setup.md](docs/setup.md)。
